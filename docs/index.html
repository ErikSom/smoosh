Run the demos

git clone https://github.com/ErikSom/smoosh.git
cd smoosh
npm ci
npm run serve

Open localhost:4179. You need Node 22+ and a browser with WebGPU.

Add Smoosh to a project

npm install github:ErikSom/smoosh box2d3-wasm@5.2.0

Pass your Box2D module, world and canvas:

import { Smoosh } from '@smoosh/box2d';

const sim = await Smoosh.create({ box2d, worldId, canvas, domainWalls: true });
sim.addArea('tank', { x: 1, y: 1, width: 30, height: 18 });
sim.fill({ x: 2, y: 2, width: 8, height: 10 });
sim.adapter.addBody(bodyId);

sim.advance(deltaSeconds); // call each frame

The minimal example includes the setup and frame loop. The API page covers areas, sources, colours and cleanup.

Use the testbed

Open the panel at the top right. Samples selects a scene; Simulation contains tools and settings. Drag to stir, pinch to zoom, and use two fingers to pan.
