Smoosh runs materials on the GPU and uses Box2D for rigid bodies. The adapter exchanges body motion and reaction impulses.

  • Defaults: liquids 120 Hz, solids 480 Hz, Box2D 60 Hz.
  • Limits: 128 coupled bodies, 512 fixtures and 64 sources/fills/drains.
  • Particle capacity depends on the GPU; each scene has a fixed limit.
  • WebGPU is required. This is experimental simulation for games and interactive demos.

For custom WASM builds, see native integration. Most projects can use the standard Box2D package.
