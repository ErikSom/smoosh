The testbed opens with Pumps + waterwheel. Select scenes in Samples; copy the address bar to share a direct link such as ?sample=overlap. Set motor speed or reverse direction in Simulation → Motors. Each scene links to its own file in testbed/samples/.

To make a sample, copy one of those files and register it in testbed/scenes.mjs. The shared runner creates and destroys its Box2D world, GPU resources and joints when switching or resetting.
