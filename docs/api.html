Areas

Areas define open simulation space. Touching or overlapping areas share flow automatically; gaps keep them separate. Use boxes, circles or polygons.

sim.addArea('left', { x: 1, y: 2, width: 10, height: 12 });
sim.addArea('right', { x: 15, y: 2, width: 15, height: 12 });
sim.addArea('channel', { x: 10, y: 7, width: 6, height: 2 });

sim.domain.updateArea('channel', { enabled: false });
sim.domain.removeArea('channel');

Channels and bends are just more areas. Use updateArea() to move, resize or toggle an area, and removeArea() to delete it. With domainWalls: true, Box2D walls follow the combined outline.

Material, sources and drains

sim.fill({ x: 2, y: 3, width: 6, height: 8 }); // initial material
sim.pour({ type: 'circle', x: 8, y: 14, radius: 1, material: 'rubber' });

const source = sim.addEmitter({ type: 'circle', x: 5, y: 16,
  radius: 0.4, rate: 2400, velocity: [2, -1] });
sim.addDrain({ type: 'circle', x: 28, y: 3, radius: 0.7 });
sim.updateShape(source, { enabled: false });
sim.removeShape(source);

Materials: water, syrup, rubber, sand and putty. Use fill() before stepping, pour() while running, and erase() to remove material. Source rates are particles per second.

Colour

sim.pour({ x: 12, y: 3, width: 4, height: 5, color: [1, 0.2, 0.1] });
sim.setMaterial('syrup', { viscosity: 0.6 });
sim.setSettings({ colorMixing: 2 }); // 0 disables liquid colour blending

RGB values range from 0 to 1. Liquid colours can blend; solid colours stay on their particles.

Stepping and Box2D

sim.advance(deltaSeconds);
sim.adapter.addBody(bodyId);
sim.adapter.invalidateGeometry(); // after changing fixtures
sim.adapter.removeBody(bodyId);   // before destroying the body
sim.setSettings({ hz: 120, solidHz: 480, rigidHz: 60, iterations: 5 });
sim.step(1); // manual step

If your game steps Box2D itself, use sim.advance(dt, { stepRigidBodies: false }). Under heavy load, advance() may defer a frame while feedback finishes.

Reset and cleanup

sim.reset();   // clears material; keeps areas and bodies
sim.destroy(); // after stopping your frame loop

You own the Box2D world and any GPU device you supply. Positions use metres, velocities use metres per second, and Y points up. Boxes use their lower-left corner; circles use their centre.
